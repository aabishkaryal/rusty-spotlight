Date: 2026-11-21. Requirements v3, plan v3, the mockup, and spike S1. The project binary was not built, run, or screenshotted. The 22 MB / 18 MB footprint and the 3.5–7 ms show time are the author's, not remeasured.

**Verified today.** A deferred, never-ordered `NSPanel` on this Mac: `setLevel(101)` then `isFloatingPanel = true` leaves the level at **3**; setting it again sticks; `false` forces **0**. The current `floatingPanel` page omits this; the Leopard `setFloatingPanel:` page states it. Levels in `objc2-app-kit` 0.3.2: floating 3, modal 8, status 25, pop-up 101, screen saver 1000. `global-hotkey` 0.10.0's macOS path is a Carbon handler on the application target with `kEventHotKeyExclusive`. `objc2` 0.6 retains autoreleased returns, so the blur path's `layer` fetch is balanced. Unmarked claims are unverified.

## Findings

1. **Must-fix.** `crates/shell-macos/src/main.rs:151` then `:153`. `setFloatingPanel(true)` runs after `setLevel` and forces `NSFloatingWindowLevel` (3). `RS_LEVEL` does nothing; the logged default "popup" is not the window on screen. Set the flag, then the level, and log `panel.level()` after both. Repeat fullscreen, other Space, second display, and Stage Manager at that logged level before any provider. Level 3 is what PLAN §2.4 hoped to raise only if a fullscreen space covered it. Thread 826308 was not re-opened.

2. **Must-fix.** `main.rs:62-68`, FR-5, FR-7, FR-40. `resignKeyWindow` calls `orderOut` whenever the panel is visible. A menu, the Character Viewer, or (unverified) an input method then dismisses it, and `orderOut` re-enters AppKit from inside `resignKey`. It is unverified that a click in another app resigns a non-activating panel. Remove this dismiss. Dismiss from Escape, the hotkey, and `+[NSEvent addGlobalMonitorForEventsMatchingMask:handler:]` for left and right mouse-down. Apple's page restricts Accessibility to key-related events, so mouse-down stays inside NFR-30, and the handler does not see this app's own clicks. Defer `orderOut` with `dispatch_async` on the main queue. While `hasMarkedText` is true, Escape cancels the composition only (FR-7).

3. **Must-fix.** FR-7, FR-14, NFR-40. No requirement states arrows, Tab, or Command-number. The spike only overrides `cancelOperation:` (`main.rs:55`). The field editor delivers commands through `control:textView:doCommandBySelector:` (`NSControl`). Handle them there: `moveUp:` / `moveDown:` move the row; `insertNewline:` confirms marked text, or else runs the presented action; `insertTab:` writes the selected title into the field and re-ranks; `cancelOperation:` dismisses only with no marked text. Command-K (FR-40) replaces the table with that row's actions in this same panel. An `NSMenu` would resign key. Leave Command-1…9 out; it is not part of the Spotlight model the author asked for.

4. **Must-fix.** DS-3a, FR-11, FR-14, FR-17; `crates/core/src/rank.rs:142` and the alias test at `:189`. Ghost text, the highlight, and Return come from one presented record. `completion()` returns `None` when the title does not continue the query (`te` → Visual Studio Code). DS-3a's example and the mockup (`panel-mockup.html:36`, `:84`) assume the title continues the keystrokes. Paint the untyped tail, then ` — ` and the action, in `secondaryLabelColor`, in a non-accessible overlay, not in the field string. When `completion()` returns `None`, paint nothing. The mockup's filled chip is not in the measurement table. Return uses the stored `(item, action, painted string)`.

5. **Must-fix.** FR-10, FR-22, FR-32, NFR-11. A query is a calculation only when the whole string matches numbers, `+ − × ÷ / *`, parentheses, `%`, `of`, and currency tokens, and it contains an operator or a currency token. Reject dates, versions, and names with digits (`11/21`, `2.0`, `1Password`). `/` and `*` are operators; dates are excluded so NFR-11 holds. `$`, `rs`, and `rupees` use per-symbol settings, default `$` → USD and `rs` / `rupees` → INR, and the card shows the ISO code. `US$`, `A$`, and `AU$` are not the bare `$`. Accept `$100`, `100$`, `rs100`, `100 usd`, `100 usd inr`, and `100 usd to inr`. A pure expression with no exact title or alias starts on the calculator row; an exact app stays selected. The calculator row stays pinned at the top and does not steal a moved selection (FR-10). The presented record stores the string that was drawn; Return copies it. Fetch a pair only when the cache is older than one hour and no fetch for that pair is running. A newer rate is a new paint.

6. **Must-fix.** FR-10a, Q16, `rank.rs:109-114`. An empty query lists only items with usage. A new database shows a bare field, so hotkey then Return launches nothing. Until any action is recorded, show running apps whose `activationPolicy` is `.regular`. Frecency takes over after that. Accessory and prohibited processes would fill the list with helpers.

Leave that flag off. Past ~466 pt, use an `NSScrollView` with an overlay scroller. Turn on width and height autoresizing before the first resize. Keep placing on the screen under `mouseLocation`.
