# Astra · Round 3

1. **Must-fix — FR-7, FR-14, main.rs:54–68, 264–268.** Give the field editor first refusal. Route interpreted selectors through `control:textView:doCommandBySelector:`. Let the input method consume composition, including candidate arrows, Return and Escape. Test that the Return which *ends* marked text cannot also launch. Outside composition, Escape closes secondary actions first, then dismisses the panel. Check the result of `makeFirstResponder:` and confirm the field’s editor receives the first character. Treat resign-key as a signal, since an owned menu or candidate interaction may temporarily take focus. Centralize idempotent dismissal and test those interactions alongside genuine outside clicks. [Apple delegate contract](https://developer.apple.com/documentation/appkit/nscontroltexteditingdelegate/control%28_%3Atextview%3Adocommandby%3A%29)

2. **Must-fix — FR-10/13/14, DS-3a, NFR-10.** Publish a single immutable presentation containing query generation, selected stable ID, action and payload, including the exact number to copy. Draw the row, suffix and trailing icon from it. Preserve manual selection by ID across insertions. Invalidate actions on edit or hide until the matching presentation is drawn. A table reload or worker callback establishes no pixel boundary. Delay drawing in tests, inject Return during selection moves and rate refreshes, and compare dispatch with an independent observation of the visible row/value. Treat uncertain transitions as no action.

3. **Must-fix — FR-3, main.rs:111–159.** Keep the initial borderless nonactivating style, key eligibility and refusal of main status. Drop the redundant full-size content flag on the borderless panel. Start the matrix at floating level with `canJoinAllApplications` and `ignoresCycle`; vary Space behavior and level independently. Apple explicitly describes eligible overlays joining another app’s fullscreen Space. Its exclusivity rule concerns `primary` and `auxiliary`, distinct from `fullScreenAuxiliary`. Record the lowest working combination over fullscreen and Stage Manager, including IME candidate visibility, Space switches and wake. Popup level is still experimental. [Apple collection behavior](https://developer.apple.com/documentation/appkit/nswindow/collectionbehavior-swift.struct/canjoinallapplications)

4. **Must-fix — FR-1/8, main.rs:248–254, 289–321.** A taken chord leaves a Quit-only menu. Manager initialization can abort before the menu works. Add Show with an explicit show action, report registration failure in the menu and keep running on initialization failure. Filter by registered ID and press state. The installed 0.10.0 Carbon backend installs an application-event-target handler. Replace silent off-main loss with a main-queue handoff when needed. Retain manager and status item for the application lifetime as today. [Crate source](https://docs.rs/crate/global-hotkey/0.10.0/source/src/platform_impl/macos/mod.rs)

5. **Should-fix — main.rs:9, 73–80, 203–207, 253–277; workspace Cargo.toml.** No evident dangling panel or field in the retained ownership chain. The risk is future reentrancy: an AppKit call inside the live TLS borrow can invoke a delegate that requests a mutable borrow, panicking in an aborting release build. Clone retained handles before calling AppKit or let a main-thread controller own them. Use typed CALayer bindings for the blur mask, remove the blanket unsafe-warning suppression and isolate diagnostic workspace queries from timing.

6. **Should-fix — DS-3/4, FR-3, main.rs:223–245.** Pointer hit-testing already handles offset display origins. Define the pointer as the summon-time tie-breaker when keyboard focus is elsewhere. Anchor the field’s top edge once, clamp into the chosen screen’s visibleFrame and resize downward with `setFrame:display:animate:` disabling animation. Pin the field with constraints, cap an NSScrollView at available height and shrink to 56 pt when empty. Re-clamp on display removal or resolution change. Align separator thickness to one backing pixel.

7. **Should-fix — DS-1/3b/6, FR-54, NFR-40, mockup:18–60.** The dark geometry follows the author’s measurements closely enough to implement. Light glass, exact Spotlight materials and contrast remain unverified. Draw the neutral inset selection in NSTableRowView while retaining native selected state. Use semantic NSColors and system fonts at the measured sizes. Keep 11 pt hints supplementary. On accessibility-display changes, provide an opaque background for Reduce Transparency and a clear selection outline for Increase Contrast. Expose the selected title, running state and action to VoiceOver. Give the variable-height result card a labeled NSButton (“Copy result”) sharing Return’s payload. Try a transparent exterior with a separate rounded, unclipped CALayer shadowPath updated on resize; check corners and outside-click hit area on light and dark desktops.

8. **Should-fix — DS-3a, FR-10a/40, Q16, mockup:73–87.** Draw completion as a noneditable overlay positioned from the NSTextView insertion point. Show a suffix only for a literal title prefix at end of input; suppress it during selection, composition or mid-string editing. Up/down moves NSTableView selection while the field retains focus. Right accepts a visible suffix; preserve ordinary cursor movement otherwise. Keep Tab/Shift-Tab for key-view traversal. Omit Command-number until visible shortcuts are wanted. Command-K opens an NSMenu for the presented app in M2. Keep the approved most-used default, show a bare field before any confirmed launch, and retain the bare-field option. Apple’s HIG supports immediate focus, live results and suggestions without prescribing Spotlight geometry. [Apple search-field guidance](https://developer.apple.com/design/human-interface-guidelines/search-fields)

9. **Must-fix — FR-10/22/23/32, NFR-11.** Reserve explicit website/Ask keywords first. Require a complete parse plus an arithmetic operator or recognized currency marker before offering a card. Preserve exact app/alias selection on collision. Freeze cases for `1Password`, dates such as `2026-11-21`, incomplete expressions, unary minus, powers and relative percentages. Parse the amount expression separately from source and target. Map USD/AED/AUD/NPR/INR explicitly, resolve ambiguous symbols by configuration and show both ISO codes before copying. Specify decimal separators, rounding and default-target identity conversions.

10. **Should-fix — FR-32, NFR-24.** Coalesce concurrent refreshes, retain last good quotes and track successful fetch, market timestamp and next retry separately. Back off on failure even with an empty cache. Cross via USD using target-per-USD divided by source-per-USD from one provider, displaying the older leg’s time. Reject missing, nonfinite or nonpositive legs. On Yahoo failure try the fallback, showing actual attribution and source age. With no cached quote offline show “Rate unavailable” with Copy disabled. Direct endpoint behavior and terms remain unverified here.

11. **Should-fix — FR-11/12, S3.** Specify deterministic ties: tier first, then a documented within-tier combination of match quality and capped preference, then normalized title and stable ID. Freeze the author’s ambiguous short prefixes before training. Record successful launches/switches only. Compare against tiers alone on the same queries before investing in a second matcher.

12. **Consider — FR-34/35, Q12/13.** Defer both until the author supplies representative questions. For known command names show local Linux examples immediately. For other input show an explicit Send action naming the configured endpoint. Disable it while pending, discard cancelled generations and make the answer’s sole primary action Copy. Unknown commands with no endpoint should stay local. Decide the API protocol and credential scope before promising arbitrary endpoint compatibility.

13. **Must-fix — PLAN §2.4, M0/S2/S3/S5/S9, §6.** Mark workspace creation and initial S1 observations complete. Reported warm timings cover in-process show only; fullscreen, other Spaces, second display, Stage Manager, wake, IME and VoiceOver remain unverified. Finish the focus matrix with selectable stub rows, then build cached discovery → deterministic prefix ranking → presented Return → NSWorkspace launch/switch. Dogfood immediately. Add usage, aliases, websites, calculator, then currency. Move comparative benchmarking, matcher competition and evaluator comparison off the app-launch critical path. Keep the external first-key/pixels and footprint gates before M1 exit.

## Three most important changes, ranked

1. Prove focus, composition and dismissal across fullscreen and displays.
2. Bind Return, completion and copy to the same presented selection and value.
3. Ship the app-launch path before broadening the providers or benchmarking alternatives.
